## Requirement
The system itself must enforce separation of duties (SoD), not just document it. A report is released only by an approver who is not its author. All three layers (assignment time, nightly and runtime) must demonstrably fire in tests.

## How MoDocument meets it today
The workbook's gap ("no approval before report release") is closed. The three layers are described in `docs/security/role-catalogue-and-sod.md` §3.

## Questionnaire answer (final)
MoDocument enforces separation of duties in the system, at three levels.

1. **Assignment.** Each user holds exactly one role, so conflicting roles cannot be combined, and role changes need a second administrator's approval.
2. **Runtime.** Whoever prepares or submits a report can never release it, even if they also hold the Approver or Administrator role. Likewise, whoever requests a change can never approve it. These attempts are refused and recorded in the audit trail.
3. **Nightly scan.** A scan re-checks every released report and every applied change. It records an alert if any document was released by its author, or any change was approved by its requester.

Automated tests demonstrate all three levels, and we confirmed the runtime refusals on a running system. Evidence SEC-024-E01.

## Test SEC-024-T01
- **Procedure:**
  1. Run `SodPolicyTest`, `MakerCheckerIntegrationTest` and `DocReleaseSodIntegrationTest`.
  2. On the live stack, an ADMIN authors a document, generates it, submits it, and tries to release it.
  3. An APPROVER then releases it.
- **Expected result:** all three layers (assignment time, nightly, runtime) demonstrably fire in tests.
- **Actual result:**
  - Assignment: the single-role structure test passed.
  - Runtime: the self-release and self-approval tests passed. Live: the author's release returned 409 and the different APPROVER's release returned 200.
  - Nightly: the scan reports 0 violations on clean data, then finds and audits a manufactured violation.
  - All 18 tests passed (`docs/compliance/evidence/A4-test-runs.md`).
- **Result:** Pass · tester: Agent A4 (automated re-performance); human sign-off required · date: 2026-10-19
