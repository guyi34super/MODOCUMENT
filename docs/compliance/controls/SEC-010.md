## Requirement
Demonstrate systematic secure code review: a human review policy plus automated static-analysis
evidence. Gate A8 acceptance: the pipeline demonstrably blocks a seeded vulnerable PR (tested once,
run link kept).

## How MoDocument meets it today
- **Review policy as code:** PR template with security and privacy checklists
  (`.github/pull_request_template.md`); `CODEOWNERS` for second-person review (`.github/CODEOWNERS`);
  the required branch-protection settings and the A8 drill runbook (`docs/security/branch-protection.md`).
- **Automated gates (CI pipeline configuration):** build, tests and frontend checks
  (`.github/workflows/ci.yml`); gitleaks over the full history, Semgrep (`p/java`,
  `p/owasp-top-ten`, `.semgrep/modocument.yml`), dependency review and `npm audit`
  (`.github/workflows/security.yml`); SBOMs, weekly Trivy image rebuild and ZAP baseline
  (`.github/workflows/sbom.yml`, `.github/workflows/image-rebuild.yml`,
  `.github/workflows/zap-baseline.yml`); Dependabot (`.github/dependabot.yml`). All third-party
  actions are pinned by commit SHA. These files reached `main` on 2026-10-10 (workbook targets:
  Dependabot 9 Oct — one day late; Semgrep and gitleaks 16 Oct — met).
- **Quarterly report:** [code-review-report-2026-Q4.md](../policies/code-review-report-2026-Q4.md),
  built from the git history of `main` since 2026-07-01: 32 merges through GitHub, 6 direct pushes,
  4 PRs merged without GitHub CI.

## Questionnaire answer (final)
MoDocument's review process is defined in the repository: every change is meant to go through a
pull request with a security and privacy checklist, approval by a code owner, and automated gates
for build and tests, secret scanning (gitleaks over the full history), static analysis (Semgrep
with the OWASP rule set), dependency and container scanning, and a weekly DAST baseline. The latest
code review report (2026 Q4 to date) shows that these controls are designed but not yet operating
consistently: six commits reached the main branch without a pull request (the last on 15 October
2026), GitHub Actions has not run jobs since 16 October 2026 (four pull requests were merged on
local test runs), and independent approval cannot yet be shown. Branch protection, a second code
owner and restored CI runners are being put in place. Evidence: SEC-010-E01.
