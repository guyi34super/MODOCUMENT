## Requirement
Produce a defensible layered architecture diagram and a matching hardening
baseline, so that an external reviewer can trace any request path and name
the control at each hop (Go-Live Security Gate item A1; the workbook also
cites A9–A12 and A16, which the 2 Oct 2026 gate document does not contain —
DOC-4).

## How MoDocument meets it today
- **Architecture document written:**
  [security-architecture.md](../policies/security-architecture.md) — hybrid
  model (AWS af-south-1 plus the optional on-premises Connector Agent),
  Mermaid diagrams of the network, the request path with the control at
  each hop, trust boundaries, and CI/admin access, each box tied to a
  Terraform resource.
- **Terraform reference:** the whole AWS design is in `infra/terraform/`
  (eight modules wired by `infra/terraform/envs/production/main.tf`;
  module list and fact register in
  [A8-infra-checks.md](../evidence/A8-infra-checks.md) §3). `terraform fmt
  -check` and `terraform validate` pass for both envs (run 2026-10-19,
  §1). **Not applied:** no AWS account exists yet.
- **Coverage gaps in IaC:** DNS (Route 53) and ACM certificates are set by
  hand (TF-110, TF-111); the two GPU model servers in the 2 Oct design are
  not in Terraform (TF-112, DOC-8). The workbook gap "Terraform coverage
  partial" therefore still holds for these items.
- **Hardening baseline:** architecture §6 — node AMI is AWS's ECS-optimised
  Amazon Linux 2023 with IMDSv2, encrypted disk, no SSH
  (`infra/terraform/modules/ecs-app/main.tf`, TF-60, TF-61); containers
  non-root with capabilities dropped (SUP-S04); database private and
  TLS-only (SUP-S06); edge WAF and origin lock (SUP-S03).
- **CIS scan of a golden image:** none. MO builds no golden image (the node
  AMI comes from AWS), and no workflow runs a CIS benchmark
  (`.github/workflows/image-rebuild.yml` and
  `.github/workflows/release.yml` run Trivy vulnerability scans only).
  `NOT IN REPO (live cloud)`.
- **Defect found that blocks the design working:** DEF-1 (interface
  endpoints use the app security group, which refuses 443) — see the
  architecture page §7.

## Questionnaire answer (final)
MoDocument is a hybrid system. The application, API, database and file
store run on AWS in Cape Town (af-south-1) across two availability zones,
all defined in Terraform. Users reach it through Amazon CloudFront with AWS
WAF and Shield Standard; the load balancer accepts traffic only from
CloudFront; the application runs as non-root containers on ECS in private
subnets; the PostgreSQL database is in private subnets with no internet
route and accepts only TLS connections from the application. Banks that
integrate their own systems may run our Connector Agent on their premises;
it only makes outbound HTTPS connections. MoDocument is pre-production: the
environment is written and validated as code but not yet deployed. The
architecture diagram, the Terraform reference and the control at each hop
are provided. Evidence: SEC-001-E01.

## Test SEC-001-T01
- **Procedure:** trace a browser request and a bank machine request
  through the diagram and name the control at each hop from the Terraform
  code; check every diagram box against a resource; run `terraform
  validate`.
- **Expected result:** an external reviewer can trace any request path and
  name the control at each hop.
- **Actual result:** both paths traced (architecture §3); every box maps to
  a resource except DNS, ACM and the GPU model servers (not in IaC);
  validate passed; DEF-1 found by reading, not by validate. Not checked
  against a deployed environment, and not yet by an external reviewer.
- **Result:** Partial.
- **Tester:** Agent A8 (static re-performance); human sign-off required.
- **Date:** 2026-10-19.

## Risk R-SEC-001
- **Risk:** an undocumented architecture hides single points of failure
  and unprotected paths.
- **Cause:** the diagram drifts from the deployed reality.
- **Mitigation:** diagram generated from and cross-referenced to
  Terraform; review on every infrastructure change; `terraform plan` drift
  check (gate A1). Likelihood, impact and residual are set in MO-031.
