## Questionnaire answer (final)
MoDocument's cryptography is specified in a written standard that lists every algorithm in use with its parameters. Data and secrets are encrypted with AES-256-GCM (96-bit random nonces, 128-bit tags); bank connection secrets use a separate key per bank derived with HKDF-SHA256 and bound to the bank; passwords and machine secrets are hashed with Argon2id; signatures use HMAC-SHA256. In transit we allow TLS 1.3 and 1.2 only, using the AWS policies ELBSecurityPolicy-TLS13-1-2-2021-06 on the load balancer and TLSv1.2_2021 on CloudFront, and the database connection is TLS-enforced and certificate-verified. Cloud data at rest uses AWS KMS customer-managed keys with automatic yearly rotation for the database and document storage. Keys live in AWS Secrets Manager and are never in code or images. MD5, SHA-1 (outside the TOTP standard), DES/3DES, RC4, ECB and TLS below 1.2 are prohibited, and an automated code-scanning rule blocks them; it found no violations on 19 Oct 2026. The live TLS scan will be produced when the environment is deployed (evidence SEC-029-E01).
