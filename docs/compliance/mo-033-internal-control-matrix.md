# MO-033 — Internal Control Matrix

**Task MO-033: Internal control matrix.** Deliverable: Internal Control Matrix.
**Linked DPO task:** MO-059 (data-protection controls for the internal control audit).

This matrix lists every control that the pack documents establish: the 57 workbook controls (02 Security, 03 Software Engineering, 04 IT Infrastructure & Operations; IDs kept) and 18 governance, organisational and data-protection controls that are not workbook rows (`ICM-01`…`ICM-18`). For each control it gives the objective, a description, the type, the owner (from the RACI in `docs/compliance/mo-001-governance-structure.md`), the frequency, the evidence the control produces, the risks it treats (`docs/compliance/mo-031-technology-risk-register.md`) and where its test procedure is. The test results are in `docs/compliance/mo-034-internal-control-audit-report.md`.

## 2. How to read the matrix

| Column | Meaning |
|---|---|
| ID | Workbook control ID, or `ICM-nn` for a control that is not a workbook row. "Related ID" names a decision in the approval matrix (`D1`…`D20`, MO-001 §4) or a control ID from another pack that the workbooks cite. |
| Type | **Preventive** stops the event; **detective** finds it; **corrective** limits or reverses it; **directive** sets the rule. **Automated** runs in code or infrastructure; **manual** is done by a person. |
| Owner | The workbook action owner for workbook controls; the RACI R/A for ICM controls. |
| Evidence produced | What the control leaves behind and where a reviewer finds it today. |
| Test procedure | `<CID>-T01` on the control page (procedure, expected and actual result); ICM controls are tested in MO-034 §5.2. |
